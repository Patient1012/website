# Attribution

This website recreates the visual interface of [cgit](https://git.zx2c4.com/cgit/), 
a fast web frontend for git repositories written by Jason A. Donenfeld and the cgit Development Team.

## Derivation
- CSS styling based on `cgit.css` from the cgit project (GPL v2)
- JavaScript behavior based on `cgit.js` from the cgit project (GPL v2)  
- HTML structure and layout inspired by cgit's UI generation code (ui-shared.c, ui-repolist.c, ui-summary.c, etc.)
